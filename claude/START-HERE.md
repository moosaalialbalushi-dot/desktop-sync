# Claude launch pad
Open sessions from this folder. Everything is stored in ~/MacStorage/Moosa (on the Mac, not iCloud); the links here are shortcuts:
- **Projects** = every piece of work, one folder per topic: Projects/<Company>/<date>_<Topic>/ (files + README)
- **Chats** = every session as a readable text file (Claude Code + Hermes), refreshed daily at 22:15; index in Chats/INDEX.md
- **Moosa** = the whole structure; start with Moosa/00_INDEX.md (CRM, client database, trade data, memory map)
Rule for any AI session: save outputs in Projects/<Company>/<date>_<Topic>/, never loose on the Desktop.
